A clear guide to using Cyber Guardian responsibly.

01 / PURPOSE

Educational security checks

Cyber Guardian provides basic awareness checks for passwords, links and email addresses. Results are indicators, not guarantees, and should not replace professional security tools or advice.

02 / YOUR RESPONSIBILITY

Think before you trust

You are responsible for verifying websites, messages and accounts before sharing information. Never enter a real password into a tool unless you fully trust how it handles that data.
